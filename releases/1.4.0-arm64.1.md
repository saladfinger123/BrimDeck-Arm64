Windows ARM64 fork of BrimDeck. The app stays WPF on .NET 10 and still publishes win-x64.

- Self-contained win-arm64 and win-x64 builds. WPF is not trimmed and not NativeAOT.
- The installer payload is the architecture you run. The Inno Setup stub itself is x64 and is emulated on ARM64 Windows. An ARM64 package will not install on x64 Windows, and the x64 package will not install on ARM64 Windows.
- Updates come from saladfinger123/BrimDeck-Arm64 and refuse a package whose product, repository or architecture does not match this copy. Upstream BrimDeck can stay installed beside it. Settings for this fork live in %LOCALAPPDATA%\BrimDeck-Arm64 and are kept across install and upgrade. Uninstall deletes them only if you ask.
- CPU, memory, network, disk and process readings are unchanged in source. Network rates that cross a sleep or a counter reset are left unavailable instead of being shown as zero.
- Intel CPUID, MSRs and AMD SMN are not called from an ARM64 process, and this build does not install PawnIO or the sensor service there. GPU name, engine utilization and memory usage still use DXGI, DXCore and PDH. The Windows GPU temperature path still uses D3DKMT. nvapi64.dll, the AMD and Intel private libraries, and nvidia-smi are not loaded on ARM64 until a Windows ARM64 build of those files is verified. A missing vendor reading is not shown as zero. There is no direct NVML binding. Leaving those extras unloaded is not a GPU acceptance test.
- The UI keeps one pending sample, so a slow frame applies the newest snapshot rather than replaying older ones.
- This build is not Authenticode signed. SmartScreen may warn. No measurement on the user's machine is included.

BrimDeck 的 Windows ARM64 fork。应用仍是 .NET 10 上的 WPF，并继续发布 win-x64。

- 自包含 win-arm64 与 win-x64。WPF 不裁剪，也不使用 NativeAOT。
- 安装包里的程序是对应架构。Inno Setup 的安装器 stub 本身是 x64，在 ARM64 Windows 上会走模拟。ARM64 包不能装到 x64，x64 包不能装到 ARM64。
- 更新只来自 saladfinger123/BrimDeck-Arm64，产品、仓库或架构不符的包会被拒绝。可以和上游 BrimDeck 同时安装。本 fork 的设置在 %LOCALAPPDATA%\BrimDeck-Arm64，安装和升级都保留；只有卸载时勾选才会删除。
- CPU、内存、网速、磁盘和进程的读取仍在。跨越睡眠或计数器回退的网速标为不可用，而不是显示成 0。
- ARM64 进程不调用 Intel CPUID、MSR 和 AMD SMN，也不安装 PawnIO 或传感器服务。显卡名称、引擎利用率和显存占用仍走 DXGI、DXCore 和 PDH，Windows 的 GPU 温度路径仍走 D3DKMT。在核到 Windows ARM64 程序之前，ARM64 不加载 nvapi64.dll、AMD/Intel 私有库和 nvidia-smi。没有厂商读数不会显示成 0。项目不直接绑定 NVML。不加载这些增强不等于 GPU 已经验收。
- 界面只保留一份待投递的采样，卡顿时用最新快照，不再把旧快照逐个补上。
- 此构建没有 Authenticode 签名，SmartScreen 可能提示。没有用户机器上的实测数据。
